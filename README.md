File System Representation and Search Using BFS and DFS

Objective

To represent a file system as a graph using an adjacency matrix and search files using BFS and DFS algorithms.

Concepts Used

- Graph
- Adjacency Matrix
- Breadth First Search (BFS)
- Depth First Search (DFS)
- File Searching

Programming Language

C

Features

1. Represents files and folders as graph nodes.
2. Uses an adjacency matrix.
3. Performs BFS traversal.
4. Performs DFS traversal.
5. Searches for a specified file.
6. Displays File Found or File Not Found.

How to Run

Compile and execute the C program using a C compiler.
